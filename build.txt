build

방법1 :
1. vite.config.js
export default defineConfig({
  plugins: [react()],
  base: '/LearnReact/TodoList/',    // 반드시 레포 경로와 일치
  build: {
    outDir: 'docs/TodoList'         // 빌드 결과를 레포의 docs/TodoList로 생성
  }
})

2. package.json
"homepage": "https://chayoungsim.github.io/LearnReact/TodoList"

3. 빌드 커밋 푸시
# 1) 의존 설치 (필요하면)
npm install

# 2) 빌드
npm run build

# 3) 결과( docs/TodoList )를 깃에 추가 & 푸시
git add docs/TodoList
git commit -m "chore: add TodoList build to docs/TodoList for GitHub Pages"
git push origin main



방법2 :

1. 로컬
npm install --save-dev gh-pages


2.
package.json 수정

{
  "homepage": "https://chayoungsim.github.io/LearnReact/TodoList",
  "scripts": {
    "predeploy": "npm run build",   // build 명령어가 존재하면 이 줄 유지
    "deploy": "gh-pages -d dist"    // 빌드 결과가 dist일 경우, build라면 -d build
  }
}

3.
npm run deploy
