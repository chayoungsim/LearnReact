🎨 Range Input 디자인 커스터마이징

다양한 스타일 적용 방법을 알아봅시다

1. 기본 스타일 리셋 (필수!)

50
/* 트랙(레일) 스타일 */ input[type="range"] { -webkit-appearance: none; /* 기본 스타일 제거 (필수!) */ width: 100%; height: 8px; background: #ddd; border-radius: 5px; outline: none; } /* 썸(손잡이) 스타일 - Chrome, Safari, Edge */ input[type="range"]::-webkit-slider-thumb { -webkit-appearance: none; width: 20px; height: 20px; background: #4CAF50; border-radius: 50%; cursor: pointer; } /* 썸(손잡이) 스타일 - Firefox */ input[type="range"]::-moz-range-thumb { width: 20px; height: 20px; background: #4CAF50; border-radius: 50%; cursor: pointer; border: none; }
중요! -webkit-appearance: none; 을 반드시 추가해야 커스텀 스타일이 적용됩니다.

2. 그라디언트 디자인

5. 호버 효과 (마우스 올리면 반응)

50
.range-hover { transition: background 0.3s; } .range-hover:hover { background: #bbb; /* 호버 시 배경색 변경 */ } .range-hover::-webkit-slider-thumb { transition: transform 0.2s, box-shadow 0.2s; } .range-hover::-webkit-slider-thumb:hover { transform: scale(1.3); /* 호버 시 크기 증가 */ box-shadow: 0 0 15px rgba(52, 152, 219, 0.5); /* 그림자 효과 */ }
