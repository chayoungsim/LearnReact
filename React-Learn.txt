# useEffect
함수 컴포넌트 내에서 렌더링 후에 실행되고, 상태 변화나 props 변경을 감지해 특정 작업을 수행할 수 있게 해주는 Hook입니다.
useEffect 내 함수는 컴포넌트가 렌더링된 후, DOM이 업데이트 된 직후에 실행됩니다.

1. useEffect(() => { ... }, [])
 주로 이벤트 등록이나 초기설정시 사용합니다.

# useRef 
React에서 DOM 요소나 변하지 않는 값을 저장하거나 참조할 때 사용하는 Hook 함수입니다.
특정 DOM 요소를 조작할 때
리렌더링 없이 값을 저장하고 싶을 때
외부 라이브러리 연동 - GSAP, Swiper 등에서 DOM을 직접 제어할 때

fetch()는 브라우저 내장 API로, 지정한 URL에서 데이터를 요청합니다.
await를 붙이면 fetch가 완료될 때까지 기다렸다가 결과(Response 객체)를 res 변수에 저장합니다.

axios는 Promise 기반 HTTP 클라이언트입니다.
즉, fetch()처럼 API 서버와 통신(데이터 요청·전송)을 도와주는 라이브러리입니다.

하지만 fetch()보다 편리하고 가독성이 좋아서 React 프로젝트에서 거의 표준처럼 사용됩니다.

<Outlet />은 React Router에서 매우 중요한 컴포넌트로,
간단히 말해 “자식 라우트를 표시하는 자리(placeholder)” 입니다.

useParams는 React Router에서 제공하는 훅(Hook) 으로, URL 경로(path)에 포함된 동적 파라미터 값을 가져오는 역할을 합니다.

React 함수형 컴포넌트와 useReducer 훅을 불러옵니다. 
useReducer는 상태가 객체로 복잡하거나 업데이트 로직이 여러 갈래로 갈 때 useState보다 더 명확한 패턴을 제공합니다.
