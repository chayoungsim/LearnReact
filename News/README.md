# News API

## 3단계 실전 — News 사이트
+ newsapi에서 제공하는 API를 사용 (Local에서만 가능 로컬학습용)
+ 첫 페이지 로드 시 일반(general) 카테고리의 최신 뉴스가 자동으로 표시됩니다
+ 카테고리 탭을 클릭하면 해당 카테고리의 뉴스로 즉시 전환됩니다
+ 뉴스 카드를 클릭하면 상세 페이지에서 전체 내용을 확인할 수 있습니다


### axios론 뉴스 api 호출 ( 로컬 학습용으로만 사용 가능 )
https://newsapi.org/ - 회원 가입 후  API키를 이용하여 데이터에 접근

### 설치
- npm install react-router-dom
- npm install axios
